# 我们的日历 · 异地恋情侣同步日历

一个专为异地恋情侣设计的 Web 日历应用：两个人共用一个日历，实时同步彼此的日程，并正确处理时差——即使一个在北京、一个在纽约，也能一眼看清「同一时刻，两边各是几点」。

数据存储在 **Supabase 云端数据库**，永久保存，重启/重新部署都不会丢。

## ✨ 功能特性

- **双人配对**：一方创建空间生成 6 位「情侣邀请码」，另一方输入即绑定，无需邮箱注册。
- **登录码（账号）**：每个人有专属「登录码」，退出 / 换设备后在「登录」页输入即可回到自己的空间，不再依赖浏览器缓存。
- **一键备份 / 恢复**：设置里「导出数据」下载全部数据（JSON），「导入数据」一键恢复。
- **共享日历**：月 / 周 / 日三种视图，移动端优先、响应式设计。
- **日程增删改查**：普通日程、待办（可勾选完成）、纪念日；支持重复（每天/每周/每月）、提醒、备注。
- **双人颜色区分**：一眼看出每条日程是谁安排的。
- **实时同步**：一方增删改，另一方界面 1～2 秒内自动更新（WebSocket，无需刷新）。
- **时区 / 时差（核心）**：
  - 所有日程统一以 **UTC** 存储；
  - 创建时按**自己的当地时间**输入；
  - 日历主视图按**查看者自己的时区**换算显示；
  - 点开详情同时显示**我的时间 + 对方时间 + 时差**；
  - **双视角切换**：一键在「我的时间」和「对方时间」之间切换整个日历；
  - 正确处理**夏令时（DST）**，并常驻显示「对方现在几点 · 时差多少」。
- **恋爱天数**：设置「在一起的日子」后首页常驻显示「在一起 X 天」。
- **共同空闲时间**：周/日视图可开启「高亮共同空闲」，绿色标出两人都没安排的时间段。
- **提醒**：应用内提示 + 浏览器通知（需授权）。

## 🚀 本地启动

需要 Node.js ≥ 18。

1. 先按 [`SUPABASE-迁移.md`](./SUPABASE-迁移.md) 完成「建项目 + 建表 + 拿密钥」三步。
2. 配置环境变量：把 `.env.example` 复制为 `.env`，填入你的两个密钥：
   ```
   SUPABASE_URL=https://你的项目ID.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=你的service_role密钥
   ```
3. 启动：
   ```bash
   cd couple-calendar
   npm install
   npm start
   ```
4. 浏览器打开 **http://localhost:3000**（手机和电脑在同一局域网时，也可用手机访问 `http://<电脑局域网IP>:3000`）。

> 未配置 Supabase 时，服务能启动并显示界面，但一操作会提示「缺少环境变量」——照上面第 2 步配好即可。

## 📱 使用说明

1. **创建空间**：一方打开页面 →「创建空间」→ 填昵称和时区（会自动识别）→ 得到邀请码。
2. **邀请对方**：把邀请码发给对方（页面顶部横幅 / 设置里都能复制）。对方打开页面 →「加入空间」→ 输入邀请码 + 自己的昵称和时区。
3. **看日程**：月/周/日视图切换；点某天进入日视图；点空白处（周/日视图）快速新建。
4. **时差**：
   - 顶部常驻显示「对方现在几点 · 时差」；
   - 点「我的时间 / 对方时间」切换整个日历的视角；
   - 点开任意日程，详情里同时显示两边真实时间。
5. **共同空闲**：周视图勾选「高亮共同空闲时间」。
6. **恋爱天数**：设置 →「在一起的日子」填上纪念日。
7. **退出/换空间**：设置 →「退出 / 换空间」。退出后可用「登录码」在登录页重新进入。
8. **登录码**：设置里「我的登录码」查看 / 复制，请妥善保存（这是找回空间的钥匙）。
9. **备份/恢复**：设置里「导出数据」下载备份 JSON；「导入数据」选择备份文件即可恢复。

## 🧱 技术栈

| 层 | 选择 | 理由 |
|---|---|---|
| 后端 | Node.js + Express | 轻量、生态成熟、零学习成本 |
| 实时 | `ws`（WebSocket） | 纯 JS、无需外部服务即可实时同步 |
| 存储 | Supabase Postgres（免费） | 云端持久保存，重启/重新部署不丢数据 |
| 前端 | 原生 HTML/CSS/JS（ES Module） | 无需构建步骤，克隆即跑，易维护 |
| 时区 | `Intl` + IANA 时区 | 浏览器原生，自动处理夏令时 |

## ⚠️ 已知说明

- **重复日程**：编辑或删除某个重复日程，会作用于整组（所有重复次数）。这是当前简化模型。
- **提醒**：采用应用内提示 + 浏览器 Notification（页面打开时有效），并非后台 Web Push（Service Worker）。若需要手机锁屏也能收到，可后续升级为 Web Push。
- **多设备**：同一成员可在多个设备登录，但同一时刻每个成员只有一种颜色标识。

## 🔒 安全

- 每个「情侣空间」数据完全隔离，邀请码足够随机。
- 成员 token 不会下发给对方，避免互相冒充。
- Supabase 的 service_role 密钥**仅存在于服务端**，浏览器永不直接接触 Supabase；数据表已开启 RLS，外部匿名访问被拒绝。
- 无任何第三方追踪。
